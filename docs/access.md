# Доступ Everty

Вкладка «Доступ» работает с `https://multilink.tolkovmeste.com`. Получите ключ у администратора, введите его шесть символов и нажмите «Активировать». Регистр букв не важен. Срок подписки начинается при активации и отображается в клиенте.

Код используется для первоначальной активации одного клиента. После успешной активации повторный ввод при запуске не нужен: токен доступа сохраняется в защищённом хранилище Windows DPAPI. Если ответ был прерван, повторите активацию в том же клиенте. Не удаляйте защищённые настройки между попытками. Для другого устройства нужен отдельный код.

Кнопка обновления получает актуальные серверы и срок доступа. Для изменения списка сначала отключитесь. Доступ проверяется перед подключением и периодически во время работы. Истечение срока или отказ сервера доступа останавливает подключение через управляемую подписку. Сторонние подписки можно добавлять отдельно.

Публикация клиента не развёртывает сервер. Пока сервис на домене не запущен, активация не будет доступна. Серверная реализация и административные инструменты не входят в этот репозиторий.

## Формат конфигурации

Клиент поддерживает JSON `everty.multilink`, версия 1. Документ содержит идентификатор профиля, название, ревизию, время выдачи и окончания доступа, а также список серверов с ID, именем и VLESS URI. До импорта проверяются версия, срок и корректность серверов. Локальные настройки маршрутизации серверным документом не заменяются.

В [примере](../crates/multilink-core/fixtures/profile.example.everty.json) используются только вымышленные адреса и тестовые реквизиты. Рабочих ключей или подписок в примере нет. Собственный формат не скрывает VPN-реквизиты от владельца клиента: документ нужен программе для подключения.
